# Minecraft Tierlist

A tierlist ranking application for Minecraft players, servers, and items, inspired by MCPVP.

## Features

- Drag-and-drop tierlist creation
- Multiple ranking categories (S, A, B, C, D, F)
- Support for Minecraft players, servers, items, and more
- Save and share tierlists
- Responsive web design

## Technologies

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js/Express (optional)
- Storage: Local Storage / Database

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Create your tierlist by dragging items into tier categories
